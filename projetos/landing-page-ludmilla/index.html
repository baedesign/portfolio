12 — Landing Page Ludmilla Neres

Uma experiência digital que acolhe antes mesmo da primeira conversa.

Cliente

Ludmilla Neres

Projeto

Landing Page

Minha atuação

UX/UI · Web Design · Front-end

Tecnologia

HTML · CSS · JavaScript

ludmillaneres.com.br

Contexto

A identidade precisava continuar reconhecível quando virasse experiência.

Depois da construção da identidade visual de Ludmilla Neres, o projeto avançou para uma landing page voltada à apresentação do atendimento psicológico e à aproximação com novos pacientes.

A interface precisava comunicar acolhimento e profissionalismo, organizar uma quantidade relevante de informação e conduzir ao contato sem transformar uma decisão sensível em uma experiência excessivamente comercial.

01

Acolhimento

Uma linguagem visual calma, humana e coerente com a experiência que a profissional deseja oferecer.

02

Clareza

Informações sobre temas, atendimento e dúvidas organizadas em uma jornada simples de percorrer.

03

Ação

CTAs presentes nos momentos certos para facilitar o primeiro contato sem pressionar a navegação.

Arquitetura da página

Uma jornada que reduz dúvidas antes de pedir uma decisão.

A estrutura começa pela proposta de valor, apresenta a profissional, organiza os temas acompanhados na clínica e explica como funciona o processo terapêutico.

Benefícios, perguntas frequentes e chamadas para contato entram depois, quando a pessoa já teve contexto suficiente para compreender a proposta.

Proposta de valor→Sobre→Temas→Atendimento→Benefícios→Dúvidas→Contato

Conteúdo e hierarquia

Temas complexos apresentados com uma leitura leve.

Cards organizam os principais temas atendidos sem transformar a página em uma lista clínica. Ícones lineares, títulos curtos e textos de apoio criam pontos de entrada rápidos para quem está apenas explorando a página.

Como posso ajudar

Direção visual

A marca continua presente sem competir com o conteúdo.

Pulsar marca os pontos de ação; Inspirar sustenta as áreas de maior contraste; Respirar, Iluminar e os neutros constroem pausas e camadas mais suaves.

Retratos, grandes áreas de respiro, cantos arredondados e hierarquia tipográfica preservam a sensação de proximidade da identidade visual dentro de uma interface funcional.

Responsividade

A experiência se reorganiza sem perder o acolhimento.

No mobile, navegação, cards e conteúdos passam para um fluxo vertical. O menu se torna compacto e a hierarquia permanece clara mesmo com menos espaço disponível.

Role dentro do mockup para explorar a versão mobile.

Front-end

Uma landing page independente, responsiva e fácil de manter.

O projeto foi desenvolvido em HTML, CSS e JavaScript puro, mantendo conteúdo, estilos e interações separados para facilitar futuras alterações e publicação independente.

A implementação inclui header fixo, navegação por âncoras, menu mobile, animações de entrada, FAQ expansível, carrossel de depoimentos e configurações centralizadas para dados de contato.

Projeto navegável

O case explica as decisões. A landing page mostra como elas funcionam juntas.

A versão incorporada preserva o projeto de desenvolvimento enviado para o portfólio. Dados de contato e conteúdos marcados no código como provisórios devem ser atualizados antes de uma publicação definitiva.
